# Wallet 核心概念

本文集中定义理解 Wallet 所需的核心对象、协议和术语，并说明它们在本项目中的职责与边界。具体运行流程、接口字段和安全要求以各自链接的权威文档为准；能力状态以代码和测试为准。

## 项目模型

Wallet 是用户控制密钥的浏览器钱包。它管理本地钱包和账户，通过 Provider 接收 DApp 请求，由运行时检查来源、权限和网络，再在需要时展示审批并执行查询、签名或交易。链适配器处理链专属地址和交易格式；本地密钥安全边界负责秘密的保护和签名。身份协议、站点权限和链上账户是相关但独立的概念。

```text
用户 ──管理/确认──> Wallet
                      ▲  │
       请求/响应       │  ├──权限检查与审批──> 站点权限
DApp <── Provider ────┘  ├──链操作──────────> 链适配器 ──> RPC
                         └──身份出示/授权────> SIWE / UCAN 等协议
```

## 容易混淆的概念

| 概念 A | 概念 B | 关键区别 |
| --- | --- | --- |
| 钱包账户 | 站点权限 | 账户是 Wallet 持有和管理的数据对象；站点权限记录特定来源被允许访问的范围。账户存在不表示任何站点已获授权。 |
| 站点权限 | 用户审批 | 权限允许某类访问；签名和交易等敏感操作仍需针对具体请求审批。连接成功不意味着后续操作自动通过。 |
| chainKey | EVM chainId | chainKey 是跨命名空间的内部网络标识；EVM chainId 是 EIP-1193 使用的数字网络编号。Tron、Bitcoin 和 Solana 不能解释为 EVM chainId。 |
| 链适配器 | Provider | 适配器封装链数据和交易；Provider 定义网页如何向钱包发请求。某条链有适配器不表示它已有网页 Provider 协议。 |
| 签名器 | MPC | 签名器是执行签名的组件接口；MPC 是一种分布式计算/密钥管理方案。本项目当前 MPC 签名由专门服务编排，不等于普通本地 Signer。 |
| DID / Presentation | 链地址 | DID 标识身份，Presentation 是按请求出示的身份声明；地址是特定链上的账户标识。它们可关联，但不能互相替代。 |
| Wallet 身份能力 | 应用会话/授权 | Wallet 可识别或签署身份相关材料；应用服务仍须自行验证凭证、建立会话并执行业务权限判断。 |
