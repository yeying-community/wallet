# 协议规范目录

本目录是 Wallet 对外协议的唯一权威入口。协议定义请求、响应、用户确认、服务端验证和错误语义；具体 SDK 用法由 web3-bs 文档说明。

## 基础协议

- [连接协议](./连接协议.md)：EIP-1193 Provider、标准 RPC、账户连接、连接请求和授权撤销。
- [权限协议](./权限协议.md)：Provider 账户/资料权限、查询与撤销，以及 UCAN 能力委托和跨服务授权。
- [门限协议](./门限协议.md)：门限钱包角色、Keygen/Sign/Refresh 流程、会话状态和安全边界。
- [错误码](./错误码.md)：所有协议共用的错误码和用户提示。

## 登录认证

- [连接协议](./连接协议.md)：含 EIP-4361 SIWE 登录消息、钱包展示和服务端验签要求。
- [身份协议](./身份协议.md)：Wallet Identity 资料授权和身份出示能力。
