# 协议规范目录

本目录是 Wallet 对外协议的唯一权威入口。协议定义请求、响应、用户确认、服务端验证和错误语义；具体 SDK 用法由 web3-bs 文档说明。

## 基础协议

- [钱包连接协议](./钱包连接协议.md)：EIP-1193 Provider、标准 RPC、账户连接、连接请求和授权撤销。
- [钱包权限协议](./钱包权限协议.md)：`wallet_requestPermissions` 权限声明、查询和撤销。
- [钱包错误码](./钱包错误码.md)：所有协议共用的错误码和用户提示。

## 登录认证

- [SIWE 登录协议](./SIWE登录协议.md)：EIP-4361 登录消息和验签。
- [钱包身份协议](./钱包身份协议.md)：Wallet Identity 资料授权和身份出示能力。

## 授权协议

- [UCAN 登录协议](./UCAN登录协议.md)：UCAN 登录授权、能力委托和跨服务授权约束。
