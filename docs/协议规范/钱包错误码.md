# 钱包错误码

所有 Provider 方法和 Wallet 扩展方法使用统一错误对象：

```json
{
  "code": "IDENTITY_PRESENTATION_EXPIRED",
  "message": "身份出示证明已过期",
  "data": {
    "retryable": true,
    "userAction": "重新发起身份请求"
  }
}
```

`code` 是机器可读的稳定名称；`message` 是可记录和展示的默认提示；`data.retryable` 表示在修正条件后是否允许重新发起请求；`data.userAction` 是用户可执行的处理建议。实现不得依赖 `message` 判断错误类型。

| 错误码 | 错误含义 | 用户可见提示 | DApp 处理建议 | 可重试 |
| --- | --- | --- | --- | --- |
| `WALLET_ACCOUNT_REQUIRED` | 请求需要账户但没有可用账户 | 请先连接钱包账户 | 请求 `eth_requestAccounts`，再重试 | 是 |
| `WALLET_PERMISSIONS_INVALID` | 钱包返回的权限格式无效 | 钱包权限响应异常 | 终止请求并记录错误 | 否 |
| `USER_REJECTED` | 用户拒绝请求 | 你已拒绝本次请求 | 结束当前流程，不自动重试 | 否 |
| `WALLET_LOCKED` | 钱包处于锁定状态 | 请先解锁钱包 | 引导解锁后重新发起原请求 | 是 |
| `IDENTITY_PRESENTATION_REQUIRED` | 缺少身份出示证明 | 需要授权钱包身份资料 | 重新请求 Presentation | 是 |
| `IDENTITY_PRESENTATION_SCOPE_MISMATCH` | Presentation 未覆盖所需 scope | 身份资料权限不足 | 重新声明完整 scope 并请求 | 是 |
| `IDENTITY_PRESENTATION_EXPIRED` | Presentation 已过期 | 身份授权已过期 | 生成新的 nonce 和 Presentation | 是 |
| `IDENTITY_PRESENTATION_PROOF_INVALID` | Presentation 签名无效 | 身份证明无法验证 | 终止请求并记录安全事件 | 否 |
| `IDENTITY_EMAIL_NOT_VERIFIED` | 邮箱资料尚未验证 | 请先完成邮箱验证 | 引导用户验证邮箱后重试 | 是 |
| `IDENTITY_AVATAR_NOT_VERIFIED` | 头像资料尚未验证 | 请先完成头像验证 | 引导用户验证头像后重试 | 是 |
| `IDENTITY_USERNAME_NOT_VERIFIED` | 用户名资料尚未验证 | 请先完成用户名验证 | 引导用户验证用户名后重试 | 是 |
| `IDENTITY_WALLET_PROOF_INVALID` | DID 与钱包地址绑定证明无效 | 钱包地址证明无效 | 终止请求并要求重新建立绑定 | 否 |

服务端遇到 audience、nonce、issuer、subject 或有效期校验失败时，应映射到对应身份错误并拒绝请求；不得返回成功或复用旧 Presentation。
