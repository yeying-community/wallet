# 夜莺钱包文档中心

Wallet 定义钱包行为、协议实现、用户确认页面、密钥安全和错误码。应用接入方式以 web3-bs 文档为准。

## 术语

本文及相关协议中，`Presentation` 统一称为“身份出示证明（Presentation）”，指 Wallet 针对具体应用、`audience`、`nonce` 和 scope 生成并签名的一次性身份声明，不是网页演示文稿、长期登录令牌或 Node 会话。
